# 定位文档 · 允许你不读完（dsh-study-less 重定位 v1）

> 这份文档是产品的规范文件，不是路线图。以后任何新功能，先问它违反不违反第五、八节；违反就不做。

## 〇、一句话

- **对外（可复述）**：一个允许你不读完的读书工具。
- **对内（真内核）**：把目标翻译成一条能走完的边界，并记录哪一步是你自己走的。

判断标准只有一条：**去掉 AI 之后，它还剩下什么？** 剩下的是边界与账本，这两样能成立；剩下的是精读稿与导读，这两样不成立。

## 一、服务谁

**服务**：为某个具体交付物啃大部头的人——考试、论文、项目、要讲给别人听。已经在用 AI 出结果、但无法确认自己独立性的人。读 PDF 论文与教材、在电脑上读、能接受本地文件的技术型读者。

**不服务**：想被「喂」总结的人（去 NotebookLM）；想追读完数量与打卡的人；需要移动端、云同步、多人协作的人（本轮明确不支持）。

三条来自真实使用的验证（不是推测）：

1. 随机过程只读四五章就停，**这个停是对的**——考试范围既是边界，也是停止的合法性，也是终点和证据。
2. deeptutor 让人觉得重：功能越多，欠账越多；「精通之路」停在聊天框，因为它的步骤没有指向真实对象的落点。
3. 与 AI 讨论出来的创新，事后分不清哪一步是自己想的——**归因丢失**。

## 二、诊断：三个根因

| 根因 | 表现 | 现有代码对应 |
|---|---|---|
| **度量错位** | 产品度量输入（单元学完、覆盖率、精读稿已生成），用户焦虑输出（能否独立创新） | `progress.json` 只有单元状态与 FSRS，没有「独立做成过什么」 |
| **边界缺失** | 所有未读单元默认欠着，界面持续收利息；没有「不需要」这个一等状态 | `UnitState` 只有 new/learned/reviewing/suspended |
| **归因缺失** | 不区分「我独立想到的 / 我判断后改的 / AI 给的但未验证」 | 无此概念，对话留在聊天里，不进账本 |

一句话：**它是学习平台，而要解决的是「我能不能靠自己」这件事。**

## 三、核心回路（产品只有一个回路，五步）

1. **立目标**：交付物 + 期限 + 受众。禁止接受「我想深入理解 X」这种没有交付物的目标（或降级为「随手读」，不进账本）。
2. **划边界**：从交付物**倒投影**，不是从学科树顺划。得到三态：必读 / 略读 / 不读（不读必须给理由）。显示「最小集 N 页 / 全书 M 页」。
3. **独立尝试**：最小反事实五式——换假设、加约束、找反例、做消融、迁移场景。每次 1–2 小时，**先自己写，后看 AI**。
4. **记卡点**：卡在第几步、卡在什么上、当时在犹豫什么。这是能力的唯一刻度。
5. **结案**：判定题通过 + 独立证据达标 → 归档，停止复习，从「今天」里彻底消失。

**复习卡的唯一来源**是判定题里的「没过」：答错则写一张卡，答对则退役。卡片不自己生长，所以队列不会变成负债；结案时该目标的卡一并删除。

**结案是本产品的核心动作**，也是它和所有读书工具的分界线：Anki 的卡永远到期，Readwise 的高亮永远在流入，Notion 的页面永远未完成——没有人做「关闭」。读书人最大的精神负担不是读得少，是关不掉。

**回路之外：阅读面（不记账）。** 边界确定后，读的那一面只挂引导问题：按**语义块**划分（2–6 段一块，一块最多一卡，一节不超过 8 块），每条是一行过渡（指向刚读过的内容，不复述结论）加一个问题（预测／对比／回忆／迁移四选一），**不给答案、不需作答、不落盘**。

- 这一面不产生任何进度、时长、覆盖率或「已读段落」记录；右栏只显示块标题，不显示「第 N/M 块」。
- 引导卡随滚动进入块即显示，**跨页不换卡**——它陪你走完整个块。
- 小窗答疑答完即走，不落库（§6 B）。分块出错时只允许「并入上一块」，不提供拆分或编辑器。
- 判定、归因、卡点三项只在过关门产生（第 4、5 步），不得在阅读面收集。
- 引导卡的语气是口语的——像坐在旁边那只大肥鱼（可带语气词，句子短），但「只问不答」的约束不因语气放松：活泼的是说法，不是要求。

`Block`（语义块）与 `PromptCard`（引导卡）是阅读面的对象，**不进账本**；§4 的四个核心对象不因此增加。阅读面与过关门引用同一个 Block，但不共享任何状态——阅读面不知道你读没读，过关门不知道你看没看卡。

## 四、四个核心对象

| 对象 | 内容 | 关键约束 |
|---|---|---|
| **Goal** | 交付物、期限、受众、判定阈值 | 无交付物不许建；到期自动提示结案或改期 |
| **Boundary** | 每个范围的三态 + 理由 + 页数 | 「不读」是一等公民，永不进「未完成」分母 |
| **Attempt** | 一次独立尝试：做了什么、独立走了几步、结果 | 必须带归因三态之一 |
| **StuckPoint** | 卡点：第几步、卡在什么上、犹豫什么 | 允许重复出现的同一卡点累计，用于看模式 |

**归因三态**（Attempt 与结论都必须标）：

- `independent`：我不看 AI 独立想到/推出的
- `judged`：AI 给了选项，我否决/修改后采用的
- `adopted-unverified`：我直接用了但没验证的（**允许存在，但永远是黄灯**）

**结案门（closure gate）**：一个目标要结案，必须满足——判定题 ≥ 阈值，且 `independent` 证据 ≥ 3 条。达不到就只能「暂停」，不能「完成」。这一条是整个产品防自欺的机关，别删。

## 五、判定标准：可判定性阶梯

| 层 | 例子 | 可否判定 | 谁负责 |
|---|---|---|---|
| 意图 | 深入理解强化学习 | 不可判定 | 不判定，只做翻译 |
| 交付 | 能独立推导这篇边缘计算论文的第 3–5 节 | 可判定 | 工具翻译成层三 |
| 证据 | 能白板推出 Eq.12；能解释此处为何用 TD 不用 MC | 可判定 | 用户执行 |

**模糊目标不是缺陷，是入口。** 工具的价值只在两个翻译动作：层一→层二（一次，几百 token），层二→层三（一次，可人工修正）。做完，那个大词就被替换成一张有小票的单子。

## 六、AI 的位置（三处，全部可选）

- **A 划边界**：把论文/目录投影成必读/略读/不读 + 断言清单。一次性。
- **B 答疑**：卡住时问，答完即走，**不落库**、不进账本。
- **C 出题与判定**：判定题由模型按目标与裁剪范围写（用户不自己出题——那正是最难的一步）；你写答案，模型只判你写下的东西，并 diff 差异。判定题（「够了没」）就长在这里：先写答案，再判；AI 只判你写下的东西，绝不参与作答。判定结论连同 `missing` 一起落盘；`confidence < 0.6` 会被系统降级为 partial，不允许靠"看起来会"结案。

**红线**：AI 不进入「独立尝试进行中」；不预生成整节内容；没有 key 时全部功能可用。这一条既是产品原则，也是开源可持续性的前提——token 消耗被压到「一次划界 + 少量对照」。

## 七、信息架构（三个入口，多一个都不要）

1. **目标**：这张单子本身（边界 + 尝试 + 卡点 + 判定的入口）。
2. **今天**：一行「继续这个尝试」，一行「N 张待回顾」。**没有红点，没有待生成，没有欠账计数。**
3. **档案**：结案过的目标。可回看当时的证据与卡点，不允许复活成待办。

## 八、不做什么（红线清单）

1. 不做「替你读」的精读稿（导读）主流程；阅读面只出问题，不出答案（见 §3 阅读面）。旧导读可保留为实验入口，默认隐藏。
2. 不做自编书、洞察卡、知识图谱可视化作为卖点。
3. 不做刷题系统、连续打卡、排行榜、成就。
4. 不做覆盖率排名与「读完进度」叙事——分母只算必读集。
5. 不做云端账号与同步；数据是本地文件，随时可导出。
6. 不做移动端；不为窄屏妥协核心交互。
7. 不接受无交付物的目标（降级为随手读，不进账本）。
8. 不让 AI 参与独立尝试的进行中。
9. 不为开源通用化牺牲深度（见第十节）。
10. 阅读面不做任何形式的记账：不统计阅读时长、不记录已读段落、不显示块内计数、不做连续天数。进度只存在于边界页数（最小集 N 页 / 全书 M 页）与过关门结果。

## 九、阶段路线

- **阶段 0（已完成）**：文档定稿 + 文案/README 对齐。
- **阶段 1（已完成，v0.5.0）**：原文面换成原文件 PDF（Range 流式，浏览器自带预览器）；阅读器带目标上下文（交付物 / 这一步为什么）；判定题改由 AI 判你写下的答案，通过率与自评项进结案门。目标交付物、裁剪单三态、尝试 + 归因、卡点派生、判定题与结案门已实现；复习队列改由判定题答错生成的最小卡驱动，结案即归档。旧按节复习保留为「旧账」，阶段 2 再决定是否一次性迁移。
- **阶段 2**：一个月后看指标，再决定是否开源。开源前提：一句话能复述、三个入口、无 key 可用、安装 5 分钟内能建出第一个目标。

## 十、风险与失败模式

| 风险 | 触发条件 | 对策 |
|---|---|---|
| 退化回待办清单 | 目标写得太宽，边界划不出来 | 强制「交付物」字段，否则不给建 |
| 不适用于某些书 | 读物没有下游交付物 | 明确「不适用」，建议去读科普或直接读，不做兼容 |
| 归因记录变成负担 | 每次尝试要填太多 | 最多三个字段，一次点击；默认值 `adopted-unverified` |
| 个人化太强，开源即被腐蚀 | 用户要求通用化 | 加功能先过第八节红线；不满足就拒绝并说明 |
| 假精确 | 试图让工具算出「最优边界」 | 边界永远是草稿，可改可结案；不追求准确性，追求稳定性 |

## 十一、验收（自用一个月，可证伪）

- 每周独立尝试 ≥ 3 次，其中 `independent` ≥ 1 次；
- 同一卡点出现的次数逐周下降（证明缺口在被补，而不是在复读）；
- 30 天内至少完成 1 次结案；
- 目标页到开始一次尝试 ≤ 2 次点击；
- 无 AI key 时可完整走通五步；
- 「生成整节内容」的调用 < 1 次/周（证明主回路已不依赖它）。

## 十二、术语表（替换自造词）

变强清单 → **书架**；学习之路 → **阅读**；大道至简 → **笔记（实验）**；单元 → **范围**；精读稿 → **导读（实验）**；洞察卡 → **笔记（实验）**。

其中「变强清单 / 学习之路 / 大道至简」三个自造词已在本版 UI 文案中替换；「单元 → 范围」涉及数据模型与大量字符串，留到阶段 1 一起改。

## 十三、这份文档怎么用

- 加功能前先读第八节；过不了红线就不做。
- 每次想改定位，先改这里，再改代码——顺序反过来就一定会漂。
- 阶段 1 的任何实现，都必须能回答「它属于五步回路里的哪一步」；回答不上来的，就是在做可替代的那层。
